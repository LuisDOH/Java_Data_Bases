# 3. Inyección de Dependencias Simple con @Inyectar
Simule un contenedor ligero de inyección de dependencias utilizando anotaciones personalizadas y reflexión en Java, evitando instanciar objetos manualmente con new.

_Instrucciones:_

* Crea una anotación personalizada llamada @Inyectar configurada para usarse en campos (`ElementType.FIELD`) y disponible en tiempo de ejecución (`RetentionPolicy.RUNTIME`).

* Crea una clase utilitaria o de servicio (por ejemplo, `ServicioMensajeria`) que tenga un método sencillo para imprimir un mensaje por consola.

* Crea otra clase (por ejemplo, `Notificador`) que incluya un campo privado del tipo de la clase anterior, pero sin inicializarlo con new. Marca este campo con la anotación `@Inyectar`.

* En tu clase principal (`Main`), utiliza reflexión de Java para recorrer los campos de Notificador. Considere que para poder obtener los atributos de la clase se utiliza `Clase.class.getDeclaredFields())`.
Si el campo de la clase en la que queremos almacenar la instancia es de tipo private podemos hacer que nuestro iterador field pueda acceder a el a traves de `field.setAccessible(true)`
Finalmente podemos mandar a llamar al constructor de una clase usando reflexion a traves de `field.getType().getDeclaredConstructor().newInstance();`.

* Si encuentras la anotación `@Inyectar`, instancia el objeto correspondiente de forma automática, asígnaselo al campo y comprueba que puedes invocar sus métodos con éxito.

````java
// Verificamos los campos de la clase usando Reflexión
for (Field field : Notificador.class.getDeclaredFields()) {
	// Si el campo tiene nuestra anotación @Inyectar...
        if (field.isAnnotationPresent(Inyectar.class)) {
           	field.setAccessible(true); // Permitir acceso al campo privado
                
		// Creamos el objeto automáticamente y lo asignamos al campo
		Object instanciaAInyectar = field.getType().getDeclaredConstructor().newInstance();
		field.set(notificador, instanciaAInyectar);
            }
        }

````

donde `notificador` es la instancia del objeto `Notificador` al cual le queremos agregar `ServicioMensajeria`.

# 4. Validador Múltiple de Datos con Anotaciones Personalizadas

Crear un motor de validación genérico que evalúe múltiples reglas de negocio en una clase (edad y correo electrónico) utilizando diferentes anotaciones personalizadas y reflexión.

_Instrucciones:_

* Crea una anotación personalizada llamada `@ValidadorEdad` que permita configurar un parámetro entero min con un valor por defecto de 18.
* Crea una segunda anotación personalizada llamada `@EmailValido` para validar campos de texto.
* Crea una clase llamada `RegistroUsuario` que contenga al menos dos atributos privados: edad (de tipo int) y correo (de tipo String). Anota cada campo con su respectiva etiqueta (por ejemplo, asigna una edad menor al mínimo y un correo con formato incorrecto a propósito para probar las fallas).
* En tu clase principal, utiliza reflexión para recorrer todos los campos definidos en la clase `RegistroUsuario`.
* Dentro del ciclo, evalúa cada campo según la anotación que posea:
** Si tiene `@ValidadorEdad`, extrae el valor mínimo requerido y compáralo con la edad del usuario.
** Si tiene `@EmailValido`, verifica que el texto cumpla con un patrón básico de correo electrónico usando una expresión regular (ej. `^[A-Za-z0-9+_.-]+@(.+)$`).

* Imprime por consola un reporte detallado con los mensajes de error correspondientes para cada validación que falle, o un mensaje de éxito si todo es correcto.
